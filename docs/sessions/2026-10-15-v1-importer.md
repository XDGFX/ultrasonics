## Done

**Ticket 013 resolved.** Cal agreed every recommendation across three grilling rounds, after a
refresher on what is already decided. The decision is
[ADR-0017](../adr/0017-the-v1-importer.md), which is Proposed.

- Automatic, once, at the first self-host boot. It reads v1's database read-only, a `v1_import`
  marker stops a second run, and applets import disabled.
- A small TypeScript parser for v1's `repr` blobs. Python is not involved, and the pickle cache is
  never opened.
- Only Plex credentials carry across. Found that Spotify's and Deezer's v1 tokens were issued to the
  dead proxy's app, so they cannot be refreshed in v2.
- Found that 1.2.0 renamed `plex beta` to `plex`, so Plex is identified by name and version.
- Each plugin's v1 mapping is part of its Phase 2 port. The roadmap's Phase 2 exit gate and Phase 4
  migration guide are amended to match, and `CONTEXT.md` gains **v1 importer**.
